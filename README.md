# Network Intrusion Detection System
### ML Analysis of the CIC-IDS-2017 Dataset

## Current Project Overview
This project implements a machine learning pipeline to classify network traffic anomalies.
Using RFC, XGBoost, and PyTorch to compare which model better helps detect future attacks on a company's network.

## Objectives

1. Anomaly Detection: Normal vs flagged network traffic.

2. Multi-Class Classification: Detect malicious patterns like DDoS and Brute Force attacks within high-volume network data.

3. Feature Importance: Which network traffic characteristics are the most reliable red flags for threat detection.

4. Which ports are most affected or most likely to be targeted by a specific attack method.
